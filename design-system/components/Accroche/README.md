Slide « direction » : message clé en grand, options positionnées sur un axe, recommandation en bandeau.

**Groupe** : Slides génériques · **Disposition** : 04 Slide de contenu + barre horizontale · **Exemple** : `slide-26.jpg` (groupe d'assets *Exemples*)

- Message clé (forme accroche/message, x 48 / y 107) : Poppins Bold 28 texte sur deux lignes, fin du message en bleu-data. Le token typo « accroche » indique 54 pt : écart à trancher.
- Axe : flèche fine entre deux extrêmes (« Build intégral » → « Solution clé en main »), libellés Poppins 12, y ≈ 200 pt.
- Options : 3 cartes grises #eef1f4, même largeur sur 864 pt, liseré 1,5 pt de #eef1f4 (35 %) vers la couleur du statut, accent vers le haut (270°, vers l'axe) ; titre Poppins Bold 14 dans la couleur du statut ; pastille de statut en haut à droite (statut/Disponible vert-ppt, statut/En construction jaune-ppt libellée « WIP », statut/Quasi absent rouge-ppt ; Poppins 12 texte) ; puces Poppins 12 texte. Le composant Pastille associe ces statuts à vert / bleu / rose : écart à trancher.
- Recommandation : bandeau midnight-blue 863 × 46 pt (rayon-ligne) à y 442,5 ; icone-idee 28 pt blanche, texte Poppins 14 blanc, amorce en gras (« Composer plutôt que choisir : ») puis la recommandation.

À fournir : message clé et mot-clé à colorer, extrêmes de l'axe, trois options (titre, statut, puces), recommandation.
Ne pas : laisser la couleur porter seule le statut (toujours un libellé).
