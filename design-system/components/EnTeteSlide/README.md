**Groupe** : Structure · **Disposition** : 04 Slide de contenu + barre horizontale · **Exemple** : `slide-15.jpg` (groupe d'assets *Exemples*)

- Le titre dit la conclusion de la slide ; mettre en couleur un seul mot ou groupe de mots (`violet-flash` par défaut, `bleu-data` pour un préfixe du type « Prérequis : »).
- Le sous-titre précise le périmètre ou la promesse.
- Ne pas : passer le titre sur deux lignes, le mettre en capitales, changer la position de la barre.
