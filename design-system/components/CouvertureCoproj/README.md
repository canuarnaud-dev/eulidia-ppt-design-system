Couverture d'un comité projet (COPROJ), déclinaison du composant Couverture.

**Groupe** : Coproj · **Disposition** : 01 Première page · **Exemple** : `slide-60.jpg` (groupe d'assets *Exemples*)

- Sur-titre : « COMITÉ PROJET », Poppins Bold 10 CAPITALES menthe-vif.
- Titre ligne 1 : nom du projet, Poppins Bold 40 CAPITALES blanc ; ligne 2 : « Comité projet n°X » en Poppins Regular 40.
- Destinataire : « A l'attention de » + noms des participants Client en gras ; dessous « CLIENT · JJ.MM.AA ».

Ordre type d'un comité projet : Couverture → Planning → une slide StatutChantier par chantier → Reste à faire → Fin.
À fournir : nom du projet, numéro du comité, participants, date.
Ne pas : reprendre les notes ou le compte rendu du comité précédent.
